아... 어쩐지 아무리 해도 안되더라...
​
혹시 아나콘다 쓰시는 분들.
​
conda default 채널만 쓰시고요. conda-forge 채널은 지우세요.
​
뭔가 문제가 생겼나봅니다.
​
라이브러리 설치하는데 아무리 해도 안되더라고요.
​
conda-forge 채널 삭제하니 바로 됨 ㅡㅡ
​
혹시 conda로 패키지 설치하는데
​
solving environments 무한로딩 문제가 생기신다면
​
```
conda config --remove channels conda-forge
```
위 명령어가 답입니다.
​
