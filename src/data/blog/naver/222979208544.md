사실 이 기능은 크게 쓸 일이 없긴 한데
​
간혹 모델 설치과정 중에서 설치가 잘 되었는지 확인하려면 컴파일 후 exe 파일이 잘 생겼는지 봐야하는데요
​
보통 3~5개 수준이라 눈으로 세면 되는데, 간혹 50개이상의 exe 파일이 나오는 그런 모델이 있어서
​
이번에 이 기능을 알아보았습니다.
​

> 파일 개수 세기

```
ls -l | grep ^- | wc -l
```

> 폴더 개수 세기

```
ls -l | grep ^d | wc -l
```
