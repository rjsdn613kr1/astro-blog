우선 소스파일 전부 다운받으시고
​
​
​
linux 안에서 intel fortran 사용중이신 분은 HWRF 설치 하실 때, MKL 라이브러리가 필요합니다.
아래 링크로 가보면
> 🔗 **[Linux에서 MKL 설정 - Cognitive Toolkit - CNTK](https://learn.microsoft.com/ko-kr/cognitive-toolkit/setup-mkl-on-linux)**
> Learn Cognitive Toolkit 영어로 읽기 저장 Twitter LinkedIn Facebook 메일 Linux에서 MKL 설정 아티클 2023. 01. 05. 읽는 데 2분 걸림 기여자 4명 피드백 기본 CNTK 수학 라이브러리는 Intel MKL(Intel Math Kernel Library) 입니다. CNTK 이 리포지토리의 MKL-DNN뿐만 아니라 사용자 지정 라이브러리 버전 MKLML 을 통해 Intel MKL 사용을 지원합니다. MKL-DNN 및 MKLML 라이브러리 설치: 머신에 MKLML을 저장할 디렉터리를...
> *learn.microsoft.com*

```
sudo mkdir /usr/local/mklml
sudo wget https://github.com/01org/mkl-dnn/releases/download/v0.14/mklml_lnx_2018.0.3.20180406.tgz
sudo tar -xzf mklml_lnx_2018.0.3.20180406.tgz -C /usr/local/mklml
wget --no-verbose -O - https://github.com/01org/mkl-dnn/archive/v0.14.tar.gz | tar -xzf - && \
cd mkl-dnn-0.14 && \
ln -s /usr/local external && \
mkdir -p build && \
cd build && \
cmake .. && \
make && \
sudo make install && \
cd ../.. && \
rm -rf mkl-dnn-0.14
```
​
이렇게 하라고 나와있는데, 이거 에러나서 아주 살짝만 고치면 됩니다.
​
​
```
sudo mkdir /usr/local/mklml
sudo mkdir /usr/local/mklml/mkl-dnn-0.14
sudo wget https://github.com/01org/mkl-dnn/releases/download/v0.14/mklml_lnx_2018.0.3.20180406.tgz
sudo tar -xzf mklml_lnx_2018.0.3.20180406.tgz -C /usr/local/mklml
wget --no-verbose -O - https://github.com/01org/mkl-dnn/archive/v0.14.tar.gz | tar -xzf - && \
cd mkl-dnn-0.14 && \
ln -s /usr/local external && \
mkdir -p build && \
cd build && \
cmake . && \

sudo make install && \

```
이렇게 고쳐서 쓰시면 에러가 안나고 설치 될 겁니다.
