아 진짜 개빡치게 아나콘다 설치해서 라이브러리 설치를 해야되는데
​
설치가 안되는 거...
​
보통 이런 경우 conda 가 업데이트가 안되서 그런거라는 것을 알고 있었기 때문에
​
```
pip install --upgrade pip
conda update -n base conda
conda update --all
```
저번에 포스팅 했던대로 위 공식을 사용하려고 했으나...
​
아니 안되는 것임....ㅠㅠ
​

​

​
문제를 해결했다는 것이죠.
​
제 경험상으로 연구실에 윈도우 컴퓨터 쓸 때는 위 공식이 제대로 작동했습니다.

​
하지만 맥북은 (경우에 따라서 다름) 위의 공식으로 해도 해결이 안됩니다.
​
맥북은 바로
​
```
conda update --all
```
​
​
위 커맨드 하나만 입력하면 됩니다.
