- 베트남개발1 : 패쓰
​
- 이아이디 : 코로나19 테마주라고 하는데, 개별호재는 따로 없습니다. 코로나가 저에게는 이제 대수롭지 않은 그런 것이 되어버렸는데, 뉴스검색을 해보니 아직 뉴스가 많이 나오네요.
​
- 남성 : 개별호재는 없습니다. 재무정보를 살짝봤는데 지난 3년동안 적자다가 갑자기 작년에 흑자로 전환했습니다. 감사보고서를 자세히 봐야 이유를 알겠지만 일단 의심해볼만 한 종목입니다. 고수가 아니라면 건들지 않는 것을 추천드립니다.
​
- 쌍방울 : 오너리스크가 제대로 작동한 것 같습니다. 저번주에 주가가 오른것이 좀 이상하게 느껴지긴 했는데, 뭔가 문제가 생겼나 보네요. 자세한 이유를 굳이 알아야 할 것 같지는 않습니다. 오너리스크는 일단 피하고 보는게 상책이라고 생각합니다.
​
- 아남전자 : 삼성전자의 자회사 하만이 페라리 자동차 솔루션의 파트너사가 됐다고 합니다. 그리고 이 하만에게 부품을 납품하는 아남전자가 동반해서 상승하는 중입니다. 아마 삼성전자도 영향을 받아 오를 것 같네요.
​
- 삼성전자 : 역시 자회사 실적 호재로 오르는 중입니다. 오늘 종목중에 이유있는 상승은 아남전자와 삼성전자뿐인 것 같습니다. 다만 삼성전자는 차트모양새가 그리 좋은 모양은 아니니 주의해서 지켜보시길 바랍니다.
